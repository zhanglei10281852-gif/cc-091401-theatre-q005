# 领域约定

追踪戏剧巡演的箱体、封签、装载和异地交接。

## 核心对象

- 道具、服装和灯具箱：尺寸（cm）、重量（kg）、易碎标记、危险品类别、起讫城市、内容物清单
- 运输段和卸货顺序：段间可换车；装载顺序按目的站逆序（先卸的后装）
- 离线扫描与封签例外：扫码按（设备, 序列号）幂等；破封、暂扣、换箱、拆分只追加例外

## 边界

- 封舱清单摘要不可静默改变：封舱后清单与 SHA-256 摘要固化，重排不能改变已固化段，变更只能追加例外
- 危险品和超重冲突要保留具体原因：相斥类别（易燃/压缩气体/氧化剂/锂电池）不能同舱，冲突随 409 响应逐条返回
- 历史交接不可被覆盖：交接确认后再次确认或同 id 重建一律拒绝；缺箱与封条不符自动生成例外并评估后续影响
- 已确认的下一站卸货位不能被无关重排抢走，只有显式释放才能调整
- 超时提醒每个交接只触发一次，重启后未完成交接与提醒状态保持连续

时间字段使用带偏移量的 ISO 8601 字符串，外部记录保留来源和接收时间。示例数据仅用于说明字段含义。
