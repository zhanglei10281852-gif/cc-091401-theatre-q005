# 领域约定

追踪戏剧巡演的箱体、封签、装载和异地交接。

## 核心对象

- 道具箱（prop）、服装箱（costume）、易碎灯具箱（fragile_light，可含第 9 类锂电池）、
  索具（rigging）与杂项箱（misc，含烟火制品 pyrotechnic、加压喷雾 aerosol）。
- 每只箱体有尺寸（cm）、重量（kg）与危险品类别。
- 车辆由多个舱位组成：舱位有尺寸、载重上限与 `hazardCapable` 危险品适装标记。
- 运输段（leg）连接相邻城市：到离站窗口为 `arriveAfter`（最早进站，早到等待）
  与 `departDeadline`（必须离站；末站为装台必须开始的时间）。
- 封舱清单（manifest）按段固化：逐箱封签号（`S-######`）、所在舱位、装车序号、
  卸货序号与卸货位 `<City>-DOCK-NN`，附 SHA-256 摘要。
- 交接（handover）在交出方、承运方、接收方之间进行，开始即锁定下一站卸货位。
- 离线扫码记录归属于设备序列号 `deviceId` 与设备内自增序号 `seq`。
- 例外（exception）四类：`broken_seal` 破封、`held` 暂扣、`swap` 换箱、`split` 拆分。

## 规则

- 装卸顺序：后卸先装（LIFO）；默认灯具/索具先卸、道具次之、服装最后，可按段覆盖。
- 危险品相斥：pyrotechnic 与 aerosol / lithium_battery 不得同舱；
  危险品只能进入带适装标记的舱位。
- 超重、超尺寸、容积不足逐舱判定，返回箱体号、舱位号与具体数值。
- 时间窗按「进站 → 卸货(+转舱+装车) → 离站 → 行驶」链式推演，
  冲突给出可用窗口、所需时长与超出分钟数。
- 换车优先沿用原车辆；换车额外计入转舱耗时，并在段记录中固化换车说明。

## 边界（不可变）

- 所有变更以只追加事件落盘（JSONL），重启整体重放。
- 封舱清单摘要不可静默改变；同段重封出新版本，旧版本保留可读。
- 交接一旦完成不可覆盖；重复完成返回 handover_closed。
- 破封、暂扣、换箱、拆分只能追加例外，并触发后续段影响评估。
- 已被未完成交接确认的卸货位不能被重排或另一交接抢走。
- 离线扫码按 `deviceId + seq` 幂等合并；同序号不同内容拒绝，不覆盖。
- 危险品冲突、超重与时间窗冲突必须保留具体原因（箱体、舱位、数值、分钟数）。

时间字段使用带偏移量的 ISO 8601 字符串；离线记录同时保留原始扫描时间
`scannedAt` 与服务接收时间 `receivedAt`。示例数据仅用于说明字段含义。
